## 审核
- 顶栏：大号品牌、独立连接按钮与连接文本三段平分空间，按钮缺少所属功能。
- 导航：图书试验、流程库、招聘业务并列，产品主任务不明确。
- 岗位页：批量运行、编辑表单、自动化开关、候选资料和原始 JSON 堆叠为长页。
- 配置：高级数据字段和日常业务字段同等显眼，没有动作与设置的边界。
- 沟通：大量折叠区替代会话列表，难以逐人检查沟通进程。
- 配色：背景、边框、文字与按钮都偏绿，内容没有视觉重点。
- 字体与图标：大写英文标签、装饰符号、不同字号及按钮高度使层级不稳定。
- 状态：恢复和调试记录混入业务记录，缺乏岗位与执行任务的语义。

## 五行方向
产品：招聘顾问按岗位配置、执行自动化并追溯候选人沟通的工作台。
气质：克制、严谨、可控。
场景：岗位台账、执行队列、顾问沟通工作席。
重点：岗位执行进展与候选人消息时间线，颜色仅表示操作、选择和状态。
统一细节：配置版本标识贯穿岗位、消息与审计。

## 九轮调整
1. 间距：4px 网格，56px 顶栏，240px 导航，36px 控件，24/32px 页面边距。
2. 颜色：石墨中性色与白色表面，深蓝 #214fc6 作为操作色，语义状态独立。
3. 图标：lucide 风格内联 SVG，18px、1.5px 描边，无装饰 emoji。
4. 文案：业务名词替代探索、AI 营销短句和调试字段。
5. 字体：系统 UI / 苹方，14px 正文，24px 页标题，16px 品牌。
6. 布局：岗位管理、执行中心、候选人沟通、审计记录、系统设置；岗位配置独立详情页。
7. 细节：统一按钮、表格、表单与 focus 状态；编辑保留草稿及原始版本号。
8. 内容：只使用真实岗位、计数和消息；不生成装饰图或伪造图表。
9. 动效：只保留颜色和边框反馈，尊重 reduced-motion。

图书练习和通用流程入口退出产品界面，CLI 引擎保留。既有联系凭据继续用于防重发；不清空正在发送或状态不明的消息。

Lucide icon paths: https://lucide.dev, ISC license, Lucide contributors.

## 验证结果
- 127 项后端回归通过，配置版本和沟通防重发逻辑保持通过。
- 隔离 Chrome 中验证岗位详情页签、JD 与频率修改、保存载荷和版本更新。
- 验证候选人消息 / 执行依据 / 资料页签、岗位选择、执行中心、审计与系统设置导航。
- 1024、760、390、320px 无页面横向溢出；无浏览器脚本错误。
- 三份设计检查截图位于 runs/verification/enterprise-ui；没有生成装饰性图片。


## 平台化调整（2026-11-14）

主导航改为自动化任务、运行与结果、环境检查；岗位、沟通和候选人审计归入 BOSS 场景。继续使用石墨中性色与深蓝 #214fc6、56px 页头和240px侧栏。任务详情以目标、参数、结果约定为主，四阶段进度作为执行页的识别细节；完整事件默认折叠，交付数据优先展示。通用任务不显示 BOSS 的岗位字段。

隔离浏览器回归验证新任务保存、轮询期间草稿保留、快速测试触发、平台执行 API 以及320/390/760/1024px布局。截图中的测试任务和环境结果是拦截 API 的回归夹具，不代表实际业务验收。真实 Docker 环境的验证见平台运行文档。
