# 工作空间布局与交互

本轮以任务为中心重组导航，保留 cloakup 品牌、蓝色操作色和所有真实执行权限。
设计方法：unslop by Damir Sokolovsky (@heydamir), CC BY 4.0。

## 功能目录

- 工作空间
  - 工作台：任务数量、运行数量、交付进度和需要处理的事项。
  - 自动化任务：任务列表；详情内分为概览、执行设置、岗位与事实、候选人与结果、运行记录。浏览器操作仍绑定任务。
  - 待办中心：左侧选择事项，右侧查看详情、补充确认答案和处理记录。
- Agent 工作空间
  - 规划端 Agent：目标、策略、事实和计划的多轮讨论。
  - 执行端 Agent：执行解释、模拟和历史重放。
  - 共用任务与版本选择条；独立对话上下文。讨论、配置与事实、模拟与重放、验证与发布构成工作顺序。
- 平台管理
  - 执行环境：账号、浏览器容量和环境检查。
  - 系统设置：模型、Harness、存储和平台配置。

## 页面约定

1. 服务连接状态与任务运行状态分别显示。顶部仅说明 API 可访问，任务状态由任务上下文和工作台展示。
2. 对话主区域负责当前工作；右侧提供绑定任务、版本、执行状态和下一步。
3. 岗位事实在任务页只读；修改进入 Agent 草案。JD、事实、FAQ 有可读编辑字段，完整源数据保留在高级 JSON 区域。
4. 策略、时间窗口、岗位、计划、提示词分区展开，避免同时显示全部长表单。
5. 后台刷新保留表单、展开状态和会话滚动位置。
6. 两端会话隔离、测试工具隔离、配置版本校验、暂停后发布等服务端门禁保持有效。此次未修改后端运行文件或任务发布包。

## 前端文件职责

现有静态资源入口保持稳定，避免引入不必要的后端静态路由变更。

| 文件 | 职责 |
| --- | --- |
| cloakup/web/index.html | 应用外壳、分组导航和无障碍区域 |
| cloakup/web/app.js | 状态刷新、视图路由、通用组件和表单保持 |
| cloakup/web/platform.js | 工作台、任务详情、待办、执行环境和设置 |
| cloakup/web/agents.js | 两个 Agent 的会话、草案、测试、发布和结构化事实编辑 |
| cloakup/web/sourcing.js | 岗位、候选人沟通、简历和审计 |
| cloakup/web/style.css | 全局视觉基础、业务组件、工作空间布局和响应式规则 |

- 主要页面只读镜像视觉检查：工作台、任务、两个 Agent 的共享布局、配置、测试、待办、环境、设置和 390px 窄屏。

## 会话核验状态（统一展示）

任务列表、任务详情、运行详情、执行环境与恢复待办共用 `recoveryPresentation`。
持久化的 `retrying` 仅说明尚待恢复，不直接代表浏览器正在操作。

| 实际条件 | 展示 |
| --- | --- |
| 不在任务执行窗口 | 等待执行时段 · 会话待核验 |
| 任务休息 | 休息中 · 会话待核验 |
| 任务或所属执行器暂停 | 执行已暂停 · 会话待核验 |
| 规划未就绪 | 等待规划 · 会话待核验 |
| 无活动执行器 | 等待执行器 · 会话待核验 |
| 退避时间未到 | 等待下次会话核验 |
| 已到调度时间但尚未开始 | 会话待核验 |
| 目标岗位正在核验且执行器心跳有效 | 正在核验会话 |
| 核验失败并阻塞任务 | 核验失败 · 等待管理员 |
| 实际核验通过 | 会话已核验恢复 |

等待状态不会宣称“正在恢复”。预计核验时间按执行窗口或退避截止时间显示；历史失败原因仍保留于记录，当前说明使用实际调度状态。


## 任务内的执行设置

执行时间和休息属于任务配置，统一在“自动化任务 → 打开任务 → 执行设置”编辑。
概览上的“编辑执行时间”也只打开同一任务的执行设置，不跳转规划端。
规划端配置页仅展示时间摘要和返回任务设置的入口。

保存并验证在后台建立独立时间配置草案，仅替换 `config.schedule`，保留其他配置、事实与计划。
该草案 ID 按任务保存，页面刷新后可继续查看；验证状态随服务刷新。
验证通过并暂停任务后，在同页“应用到本任务”。服务端仍校验草案修订、测试签名及发布条件。
失败或未应用时，生效配置保持原版本。不存在未经验证直接修改生效时间的路径。

## 前台阻塞提醒

需要登录、平台校验、等待浏览器席位时，页面顶部持续展示原因与处理入口。
任务列表和详情优先显示真实访问阻塞，不能被一般会话待核验状态覆盖。
任务详情直接展示登录处理面板，检测操作绑定该运行实例，不依赖当前页面 URL。
访问要求解除后，提醒随状态刷新消失；仍有会话核验阻塞时，展示下一项真实阻塞。
异常详情仍保存到待办中心，顶部服务连接状态不混入业务任务状态。
